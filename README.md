# Studi Kasus: Penerapan Supervised Learning (Klasifikasi & Regresi)
Dalam materi dijelaskan mengenai pergeseran dari rule-based thinking ke data-driven thinking, serta alur kerja (workflow) Machine Learning yang mencakup prapemrosesan data, pembagian training/testing set, pelatihan model, hingga evaluasi menggunakan metrik evaluasi seperti akurasi, presisi, dan recall.
Studi kasus ini mensimulasikan pemodelan klasifikasi supervised learning untuk kelayakan pinjaman/deteksi risiko kredit (sesuai contoh materi) menggunakan pustaka Python
